# 06 — Histórias de usuário

Formato: "Como [usuário], quero [funcionalidade], para [benefício]."

## Épico 1 — Acesso e conta

- **HU01** Como pessoa idosa, quero criar uma conta com poucos passos, para começar a usar o sistema sem dificuldade. *(RF001, Essencial)*
- **HU02** Como pessoa idosa, quero entrar com segurança, para proteger minhas informações. *(RF002, Essencial)*
- **HU03** Como pessoa idosa, quero recuperar minha senha por um canal que eu controle, para não perder o acesso. *(RF003, Essencial)*

## Épico 2 — Rotina

- **HU04** Como pessoa idosa, quero registrar um compromisso com data e hora, para não esquecê-lo. *(RF005, Essencial)*
- **HU05** Como pessoa idosa, quero editar ou excluir um compromisso, para manter a rotina atualizada. *(RF005, Essencial)*
- **HU06** Como pessoa idosa, quero receber um lembrete no horário combinado, para me organizar. *(RF006, Essencial)*
- **HU07** Como pessoa idosa, quero ver o histórico de lembretes, para rever o que foi combinado. *(RF007, Importante)*

## Épico 3 — Família

- **HU08** Como pessoa idosa, quero convidar um familiar e aprovar o vínculo, para controlar quem me acompanha. *(RF008, RF009, Essencial)*
- **HU09** Como pessoa idosa, quero revogar uma permissão a qualquer momento, para manter o controle sobre meus dados. *(RF010, Essencial)*
- **HU10** Como familiar, quero enviar mensagens a quem autorizou, para manter contato. *(RF011, Importante)*
- **HU11** Como familiar, quero ver apenas as informações que me foram compartilhadas, para respeitar a privacidade. *(RF010, Essencial)*

## Épico 4 — Ajuda e segurança

- **HU12** Como pessoa idosa, quero ter contatos de confiança sempre à mão, para pedir ajuda rapidamente. *(RF012, Essencial)*
- **HU13** Como pessoa idosa, quero enviar uma solicitação de ajuda para meus contatos, para ser ouvida. *(RF013, Essencial)*

## Épico 5 — Memórias e bem-estar

- **HU14** Como pessoa idosa, quero guardar fotos e histórias em álbuns, para preservar lembranças. *(RF014, RF015, Desejável)*
- **HU15** Como cuidador autorizado, quero registrar atividades permitidas, para documentar o dia. *(RF016, Importante)*

## Épico 6 — Acessibilidade

- **HU16** Como pessoa idosa com baixa visão, quero aumentar a fonte e ativar alto contraste, para ler sem esforço. *(RF017, Essencial)*
