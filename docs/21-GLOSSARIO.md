# 21 — Glossário

- **ADR:** registro de decisão arquitetural.
- **arc42:** modelo de documentação de arquitetura.
- **C4:** modelo de diagramas de arquitetura (contexto, containers, componentes, código/implantação).
- **PWA:** aplicativo web instalável com recursos offline limitados.
- **RLS (Row Level Security):** política do PostgreSQL que filtra linhas por usuário.
- **Service role:** chave administrativa do Supabase; nunca usada no cliente.
- **Vínculo familiar:** conexão aprovada entre pessoa idosa e familiar ou cuidador.
- **Exclusão lógica:** registro marcado como excluído, sem remoção física.
- **WCAG:** diretrizes de acessibilidade do W3C.
