# App VIVA+ (celular)

Arquivo único `viva-plus.html`. Não precisa de instalação, npm ou internet para rodar.

- Abra o arquivo no navegador do celular ou do computador.
- Os dados ficam no `localStorage` do navegador (neste aparelho).
- Use Ajustes > Meus dados para salvar e restaurar cópias.

Detalhes em [LEIA-ME.txt](LEIA-ME.txt).
